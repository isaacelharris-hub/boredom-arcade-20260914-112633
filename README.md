# 🌍 Boredom Arcade — World Atlas

A premium interactive 3D world atlas built as a static GitHub Pages website.

## Features

- Interactive 3D globe
- Country hover interactions
- Flag textures on hovered countries
- Country elevation/focus animation
- Country search
- Detailed country information
- Population
- Area
- Capital
- Languages
- Currency
- Geography
- International status
- GDP
- GDP per capita
- GDP growth
- Inflation
- Unemployment
- Life expectancy
- Internet usage
- Country comparison
- Responsive mobile interface
- Glass/liquid visual design
- Smooth animations
- Automatic idle globe rotation

## Data

Country metadata is supplied by REST Countries.

Economic indicators are supplied by the World Bank API.

World geography is loaded from GeoJSON.

Flags are loaded from FlagCDN.

- HTML
- CSS
- JavaScript
- Three.js

- REST Countries
