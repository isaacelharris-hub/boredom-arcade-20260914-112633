# Boredom Arcade — World Atlas

Premium interactive country atlas built as a static GitHub Pages site.

Features:

- Interactive 3D globe
- Country polygon hover effects
- Country flag textures
- Country detail panels
- Economy statistics
- Demographic statistics
- Geography information
- Political profile information
- Search
- Country comparison
- Responsive glass UI
- Multiple fallback geography providers
- On-demand external data loading

The site is intentionally static. Public APIs are queried by the
browser when needed.
