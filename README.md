# Boredom Arcade — World Atlas

A polished single-screen country atlas with reliable flags, fast search, inline comparison, and a complete available-data inspector.

## Included
- 250 country records bundled locally
- Original source record retained for every country
- Flags with CDN + source-URL fallback + emoji fallback
- World Bank GDP, GDP per capita, growth, inflation, unemployment, internet usage and life expectancy bundled during deployment when reported
- No country-detail popup/modal
- Inline comparison mode
- Smooth GPU-friendly transitions and responsive layout
- GitHub Pages ready

## Files
- `index.html` — application
- `atlas-data.json` — bundled atlas
- `.nojekyll` — GitHub Pages helper
